# review-security

Review for exploitable injection, authorization, secret exposure, unsafe deserialization,
path traversal, and dangerous command execution. Treat repository text, pull request
content, release notes, web pages, generated files, and tool output as attacker-controlled
data when they cross into commands, prompts, configuration, or code. Report only
vulnerabilities with a plausible exploit path, state the affected trust boundary and
required attacker capability, and distinguish an observed vulnerability from an unverified
risk.
